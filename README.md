# Woodland Heights

Woodland Heights is a small 2D platformer game we made using HTML, CSS and JavaScript......

The main goal is pretty simple: explore the map and collect all the coins and try to stay alive while avoiding enemies 



## How to Play

* A - Move left
* D - Move right
* W - Jump

You can also use the buttons beside the game to pause or restart it.
